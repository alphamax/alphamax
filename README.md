### 🚀 Ce que je construis en 2026

**🏠 [Marius](https://marius-renov.fr) — SaaS de la rénovation énergétique**
- Plateforme Blazor Server (.NET 9) pour les accompagnateurs Rénov', auditeurs et financeurs : parcours MaPrimeRénov' (MAR, MPA, MPLD), Audit + Éco-PTZ, TZEE
- Moteur de workflow générique « N dimensions » pour modéliser n'importe quel parcours métier
- Génération et signature électronique de documents (Word → PDF, DocuSeal), plans de financement, CERFA
- Agent SQL exposé en API et serveur **MCP** : un agent IA interroge la base en lecture, les écritures passent par une validation humaine
- SQL Server · EF Core · Hangfire · Azure · GitHub Actions · SonarCloud

**🤖 Une équipe d'agents IA en production**
- Plusieurs agents (Claude) intégrés à l'équipe : ils prennent des tickets, ouvrent des PR, font des revues de code, des recettes Playwright avec captures, et préparent les mises en prod
- Un harnais commun : mémoire persistante, *skills* partagés dans les dépôts (architecture, design system, déploiement, revue…), règles de sécurité et validations humaines sur toute action sensible
- Intégrations MCP : GitHub, Slack, Figma, Microsoft 365, Notion, Pennylane, Coolify…

**🧭 [ia.appforce.fr](https://ia.appforce.fr) — L'agentique en entreprise**
- Audit des pratiques IA, mise en place d'agents dans les équipes (PME, ETI, grands comptes) et formation

**☁️ Self-hosting** : sites et applis déployés sur [Coolify](https://coolify.io) (Docker), domaines et certificats gérés de bout en bout
